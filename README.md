# Vasant Valley School — Website Redesign

A modern, responsive, and interactive redesign of the **Vasant Valley School** website, developed as part of the **Dettroin Full Stack Developer Internship — Website Redesign Challenge**.

The goal of this project was not to replicate the existing website, but to reimagine its digital experience with a cleaner visual identity, improved navigation, responsive layouts, thoughtful animations, and a more engaging user experience while preserving the school's original purpose and essential content.

## Project Overview

The redesigned website presents Vasant Valley School through a modern, minimal, and editorial-inspired interface.

The design uses a warm neutral colour palette with burgundy accents, large serif typography, spacious layouts, imagery, subtle interactions, and scroll-based animations to create a professional school website while maintaining a welcoming and educational identity.

The website has been designed for a consistent experience across:

- Desktop
- Laptop
- Tablet
- Mobile devices

## Key Improvements Made

### Modern UI Design

Redesigned the visual identity with a modern editorial approach using large typography, structured layouts, consistent spacing, refined colours, rounded elements, and high-quality imagery.

### Improved User Experience

Simplified the content hierarchy and page structure so visitors can quickly understand the school's identity and navigate to important information.

### Fully Responsive Design

Designed layouts specifically for desktop, tablet, and mobile screen sizes instead of relying on a desktop-only interface.

### Responsive Navigation

Created a clean navigation experience that adapts across different screen sizes and provides easy access to the main pages.

### Interactive Animations

Added subtle animations throughout the website, including:

- Scroll-triggered content reveals
- Staggered entrance animations
- Typography reveals
- Image scale transitions
- Hover interactions
- Animated decorative elements
- Interactive cards and buttons

Animations were designed to enhance the experience without distracting from the website's content.

### Improved Content Presentation

Reorganised large amounts of school information into structured sections with stronger visual hierarchy, making content easier to scan and understand.

### Reusable Components

Built reusable React components for shared interface elements and page sections to improve maintainability and consistency.

### Better Navigation & Routing

Implemented React Router DOM for smooth client-side navigation between pages without full page reloads.

### Interactive Contact Experience

Redesigned the contact page with direct call and email actions, location information, map navigation, interactive icons, and a visual map-inspired section.

### Performance-Focused Development

Used reusable components, optimised layouts, lightweight CSS animations, responsive images and modern Vite tooling to maintain a smooth browsing experience.

## Design Approach

The redesign follows four core principles:

**Clarity** — Important information should be easy to discover.

**Identity** — The interface should feel appropriate for an established educational institution.

**Engagement** — Motion and interactions should enhance the experience rather than overwhelm it.

**Responsiveness** — The website should provide a consistent experience regardless of screen size.

The colour palette combines warm off-white tones with burgundy and subtle blush shades to create a sophisticated but approachable visual identity.

## Run Locally

Clone the repository:

```bash
git clone [YOUR REPOSITORY URL]
```

Move into the project directory:

```bash
cd Dettroin-int-Samriddhi-Website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
